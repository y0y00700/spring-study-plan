# 5~6주차: JPA와 Hibernate

## 핵심 질문

- JPA 명세와 Hibernate 구현체의 경계는 어디인가?
- EntityManager가 엔티티를 관리한다는 것은 무슨 뜻인가?
- 변경 감지는 어떤 시점에 SQL로 변환되는가?
- 객체 참조와 외래키의 방향 차이는 어떻게 해결하는가?
- 지연 로딩 프록시는 언제 초기화되는가?

## 최소 실험

1. 비영속, 영속, 준영속, 삭제 상태를 관찰한다.
2. flush와 commit을 분리해 SQL 시점을 확인한다.
3. 연관관계 주인 설정 유무에 따른 외래키 결과를 비교한다.
4. N+1을 재현하고 fetch join으로 개선한다.
5. 낙관적 락 충돌을 재현한다.

## 완료 증거

- 실행 전 SQL 예측 기록
- 쿼리 수와 실행 시점 비교
- `javax.persistence` 예제를 `jakarta.persistence` 환경에 맞게 변환한 기록
